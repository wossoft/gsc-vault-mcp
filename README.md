# GSC Vault MCP Server

Find unindexed pages and keep Search Console data forever — now available to your AI tools.

This repository holds the registry listing (`server.json`) and documentation for the GSC Vault remote MCP server. The server itself is hosted by GSC Vault; this repo is its public home for the Official MCP Registry and MCP directory listings.

## Connect

- Endpoint: `https://connect.gscvault.app/mcp` (Streamable HTTP)
- Auth: OAuth sign-in with your GSC Vault account; the server requests read-only access (`mcp:read`) to one selected Search Console property.

Add the endpoint as a remote MCP server in your AI client, sign in, and your Search Console data — coverage, queries, pages, index status — becomes available to the AI, beyond Google's 16-month data window.

## About GSC Vault

GSC Vault is a Chrome extension for site owners who live in Google Search Console. It finds pages that aren't indexed and shows why, follows up until their status changes, and backs up Search Console data to your own Google Drive so you keep history beyond Google's 16-month limit.
